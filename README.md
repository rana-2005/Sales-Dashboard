
# Sales Performance Analysis Dashboard

An end-to-end sales performance analysis project built to monitor business performance, evaluate product and customer trends, and analyze branch performance against sales targets for 2024–2025.

## Tools
- Power BI (interactive dashboard and data visualization)
- Power Query (data cleaning and transformation)
- DAX (KPIs and performance measures)

## Dataset
Sales data covering branches, products, customers, employees, orders, and sales targets for 2024–2025.

## Dashboard Pages
1. **Executive Overview**: Tracks net sales, profit, profit margin, total orders, average order value, monthly sales trends, sales by category, and branch performance.
2. **Products & Customers**: Analyzes units sold, unique customers, average selling price, return rate, top-selling products, category performance, customer segments, and top customers.
3. **Branches & Team**: Monitors target achievement, actual sales versus targets, cancellation rate, average delivery days, sales representative performance, payment methods, and order status across sales channels.
